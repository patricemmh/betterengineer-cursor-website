# GitHub Pages: `discover.betterengineer.com`

This repo is **static HTML + embedded CSS + vanilla JS**. It is suitable for GitHub Pages.

## Landing page URLs

**Discover root**

`https://discover.betterengineer.com/`

Redirects to `https://www.betterengineer.com/` (main BetterEngineer site). Deep Discover paths below are unchanged.

**Manufacturing**

`https://discover.betterengineer.com/aimanufacturing/`

Deep path (parity with main site):

`https://discover.betterengineer.com/aimanufacturing/services/ai-systems-readiness-for-manufacturing/`

**Hire AI-ready engineers**

`https://discover.betterengineer.com/ai-fluent-engineers/`

Deep path:

`https://discover.betterengineer.com/ai-fluent-engineers/services/hire-ai-ready-engineers/`

**Case sensitivity:** GitHub Pages treats path casing strictly. The build publishes lowercase folders and tiny redirect pages for common typos (`AIManufacturing`, `AI-Fluent-Engineers`, and similar).

## 1. What gets published

- **Source branch:** `gh-pages` (written by GitHub Actions on every push to `main`).
- **Publish root** of that branch contains:
  - **`CNAME`** with exactly: `discover.betterengineer.com` (generated by CI).
  - **`.nojekyll`** so GitHub does not run Jekyll on the files.
  - **`index.html`** meta/JS redirect to `https://www.betterengineer.com/`. Direct `/aimanufacturing/` and `/ai-fluent-engineers/` URLs still work.
  - **`aimanufacturing/`** folder with the manufacturing LP (`--base=/aimanufacturing`). **`aimanufacturing/index.html`** is a copy of the manufacturing page.
  - **`ai-fluent-engineers/`** folder with the hire LP (`--base=/ai-fluent-engineers`). **`ai-fluent-engineers/index.html`** is a copy of the hire AI-ready engineers page.

## 2. AWS Route 53 (DNS)

Create a **CNAME** record in the **betterengineer.com** hosted zone:

| Field | Value |
|--------|--------|
| **Record name** | `discover` |
| **Record type** | `CNAME` |
| **Value / Route traffic to** | `patricemmh.github.io` |

Use your **GitHub user or organization** that owns the repo if it is not `patricemmh`. Do **not** include `https://`. Do **not** append the repository name to the CNAME target.

Propagation can take a few minutes to several hours. GitHub’s “Custom domain” check in repo settings must see this before HTTPS can be enforced.

**Note:** Apex domains use `A`/`ALIAS` records; subdomains like `discover` use `CNAME` as above.

If you still have an old **`lp`** CNAME pointing at GitHub, remove or replace it so only **`discover`** is used for this site (or you will have two hostnames).

## 3. GitHub repository settings (Pages + domain)

1. Open the repo → **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**: deploy from branch **`gh-pages`**, folder **`/` (root)**.
3. Under **Custom domain**, enter: **`discover.betterengineer.com`** and save (remove **`lp.betterengineer.com`** if it was set before).
4. Wait until the DNS check shows as valid (after Route 53 propagates).
5. Enable **Enforce HTTPS**.

After this, GitHub provisions a TLS certificate for `discover.betterengineer.com`.

## 4. Local development vs GitHub Pages

| Goal | Command |
|------|---------|
| **Local / root hosting** (paths from `/`) | `npm run build` then `npm start` |
| **Matching LP bundle** (optional local check) | `npm run build:lp-dist` then inspect `./dist/` (gitignored; same layout as CI). Preview hire LP: `npx serve dist/ai-fluent-engineers -l 5180` |

`main` branch HTML from `npm run build` is for **root** URLs only. Live **`discover.betterengineer.com/...`** builds are produced in CI into **`dist/`** and pushed to **`gh-pages`** via `build-discover-dist.js`.

## 5. Short URL: caveats (not blockers)

| Topic | Detail |
|--------|--------|
| **Old URLs** | **`lp.betterengineer.com`** and paths under **`/betterengineer-cursor-website/`** from older deploys will not serve this site after you switch DNS and GitHub to **`discover`**. Update bookmarks, ads, and email links. |
| **Canonical / SEO** | The manufacturing page still declares a canonical URL on **`betterengineer.com`** in markup. That is intentional for many teams (one primary domain). If you want **`discover.betterengineer.com`** as canonical, say so and we can adjust the built `link rel="canonical"` for the LP build only. |
| **Path naming** | **`aimanufacturing`** is lowercase and avoids spaces. Changing it later means updating **`--base`**, **`OUTPUT_ROOT`**, and this doc. |
| **Custom domain** | With `CNAME` = `discover.betterengineer.com`, traffic is scoped to that hostname. The **`/aimanufacturing`** segment comes from the published folder name and **`SITE_BASE`**, not from the CNAME file. |

## 6. GitHub Pages limits (unchanged)

| Topic | Detail |
|--------|--------|
| **One CNAME per repo** | The **`CNAME`** file is only the hostname (`discover.betterengineer.com`). |
| **Jekyll** | **`.nojekyll`** at the **publish root** disables Jekyll. |
| **Rename path** | To use another slug (for example **`/ai-manufacturing`**), change **`OUTPUT_ROOT`**, **`--base`**, and the folder name in the workflow so they stay identical. |
