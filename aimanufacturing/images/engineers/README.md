# Engineer Photos

Drop all engineer photos into this folder.

## File naming convention

Rename each file to lowercase with a hyphen before the last initial:

| Original filename | Renamed to      |
|-------------------|-----------------|
| Sarah M.png       | sarah-m.png     |
| Carlos R.jpg      | carlos-r.jpg    |
| Ana P.png         | ana-p.png       |

**Rules:**
- All lowercase
- First name, then hyphen, then last initial (no dot)
- No spaces in filenames
- Keep the original file extension (.png or .jpg)

The engineer ID in `engineers.js` must match the filename without the extension.
For example, the file `sarah-m.png` maps to the engineer with `id: "sarah-m"`.
