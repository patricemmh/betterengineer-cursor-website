## 6. Page structure (logical, layout-independent)

1. **Hero / thesis statement**
   - Purpose: state the core problem and position BetterEngineer as the answer.
   - Content type: H1 + one short paragraph + one primary CTA.
   - Component: standard page hero with headline, lede, and single CTA button.

2. **Positioning banner with supporting image**
   - Purpose: reinforce the value proposition visually.
   - Content type: a single H2 with an accompanying photograph, no body copy.
   - Component: split media/text band (image + heading). Because it has no body copy, it may be better merged into the hero or given supporting copy during rebuild (flag for business review, do not invent copy).

3. **Mission statement**
   - Purpose: articulate mission and vision.
   - Content type: H2 + one paragraph.
   - Component: simple centered prose block / narrow text section.

4. **Leadership team roster**
   - Purpose: establish credibility through named leaders.
   - Content type: seven repeated units, each = role title (eyebrow), person name, headshot image, LinkedIn link. No bios.
   - Component: responsive card grid, each card being a headshot + name + role + social icon link. Should be data-driven from a list rather than hand-written markup.

5. **Team group photo**
   - Purpose: humanize the company / show scale of the team.
   - Content type: one full-width photograph with mobile and desktop variants.
   - Component: full-bleed responsive image using `<picture>`/`srcset` (legacy uses two separate `<img>` tags toggled by CSS).

6. **FAQ accordion**
   - Purpose: handle objections and capture long-tail search intent.
   - Content type: H3 section heading + eight Q&A pairs; answer 1 has two paragraphs, answer 3 contains an intro line plus a five-item bulleted list of core values; answer 7 contains four statistics.
   - Component: accordion/disclosure list (native `<details>`/`<summary>` preferred for a static site). Should also emit `FAQPage` JSON-LD.

7. **Closing CTA**
   - Purpose: convert.
   - Content type: H2 + one paragraph + two CTA buttons (contact page, Calendly).
   - Component: full-width CTA band with primary and secondary buttons.

8. **Global header and footer**
   - Purpose: site-wide navigation and legal.
   - Content type: nav with three dropdown groups plus two CTAs; footer with seven link columns, three social icons, copyright line, and two legal links.
   - Component: shared header/footer fragments (in this repo, `footer-full.html` and the header partial), not page-specific.

## 7. Migration notes

### Content issues (flagged, NOT fixed)

- **Em dash in hero copy.** The hero paragraph contains em dash characters: `We take the hardest part of software development—finding top talent—and make it easy.` This directly violates the repo rule "Never use the em dash character (`—`) in website copy." Preserved verbatim here per the extraction rule, but the rebuild will need an approved rewrite (e.g. commas or a colon). Requires a copy decision, not a silent substitution.
- **Two H1 elements.** Both `Finding Top Talent is Tough. So We Built a Better Way.` and `Our Leadership Team` are H1. Only one H1 should survive; `Our Leadership Team` should become an H2.
- **Broken heading hierarchy in the team section.** Each team member's role is an H4 while the name is an H3, and the H4 precedes the H3. Roles and names are not really headings at all and should be plain elements, or the levels should be corrected.
