# GitHub Pages: `lp.betterengineer.com` and path `/aimanufacturing/`

This repo is **static HTML + embedded CSS + vanilla JS**. It is suitable for GitHub Pages. The manufacturing landing page is the main entry at:

`https://lp.betterengineer.com/aimanufacturing/`

`https://lp.betterengineer.com/aimanufacturing` (GitHub usually redirects to the URL below)

`https://lp.betterengineer.com/aimanufacturing/` (use this in marketing links)

**Case sensitivity:** GitHub Pages treats **`/aimanufacturing/`** and **`/AIManufacturing/`** as different paths. Only **`aimanufacturing`** (all lowercase) holds the real site. The build also publishes tiny redirect pages for **`/AIManufacturing/`** and **`/Aimanufacturing/`** so common typos still reach the LP.

The deep path still exists for parity with the main site:

`https://lp.betterengineer.com/aimanufacturing/services/ai-systems-readiness-for-manufacturing/`

## 1. What gets published

- **Source branch:** `gh-pages` (written by GitHub Actions on every push to `main`).
- **Publish root** of that branch contains:
  - **`CNAME`** with exactly: `lp.betterengineer.com` (generated by CI).
  - **`.nojekyll`** so GitHub does not run Jekyll on the files.
  - **`index.html`** minimal redirect to `./aimanufacturing/`.
  - **`aimanufacturing/`** folder with the static site. Asset and page URLs use **`--base=/aimanufacturing`**. The file **`aimanufacturing/index.html`** is a copy of the manufacturing page so `/aimanufacturing/` shows that landing first. Other built pages (home, React, and so on) stay under the same prefix if you link to them.

## 2. AWS Route 53 (DNS)

Create a **CNAME** record in the **betterengineer.com** hosted zone:

| Field | Value |
|--------|--------|
| **Record name** | `lp` |
| **Record type** | `CNAME` |
| **Value / Route traffic to** | `patricemmh.github.io` |

Use your **GitHub user or organization** that owns the repo if it is not `patricemmh`. Do **not** include `https://`. Do **not** append the repository name to the CNAME target.

Propagation can take a few minutes to several hours. GitHub’s “Custom domain” check in repo settings must see this before HTTPS can be enforced.

**Note:** Apex domains use `A`/`ALIAS` records; subdomains like `lp` use `CNAME` as above.

## 3. GitHub repository settings (Pages + domain)

1. Open the repo → **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**: deploy from branch **`gh-pages`**, folder **`/` (root)**.
3. Under **Custom domain**, enter: **`lp.betterengineer.com`** and save.
4. Wait until the DNS check shows as valid (after Route 53 propagates).
5. Enable **Enforce HTTPS**.

After this, GitHub provisions a TLS certificate for `lp.betterengineer.com`.

## 4. Local development vs GitHub Pages

| Goal | Command |
|------|---------|
| **Local / root hosting** (paths from `/`) | `npm run build` then `npm start` |
| **Matching LP bundle** (optional local check) | `npm run build:lp-dist` then inspect `./dist/` (gitignored; same layout as CI) |

`main` branch HTML from `npm run build` is for **root** URLs only. The live **`lp.betterengineer.com/aimanufacturing/...`** build is produced in CI into **`dist/`** and pushed to **`gh-pages`**.

## 5. Short URL: caveats (not blockers)

| Topic | Detail |
|--------|--------|
| **Old URLs** | Anything under **`/betterengineer-cursor-website/`** from an earlier deploy will **404** after the next `gh-pages` push. Update bookmarks, ads, and email links to **`/aimanufacturing/`**. |
| **Canonical / SEO** | The manufacturing page still declares a canonical URL on **`betterengineer.com`** in markup. That is intentional for many teams (one primary domain). If you want **`lp.betterengineer.com`** as canonical, say so and we can adjust the built `link rel="canonical"` for the LP build only. |
| **Path naming** | **`aimanufacturing`** is lowercase and avoids spaces. Changing it later means updating **`--base`**, **`OUTPUT_ROOT`**, and this doc. |
| **Custom domain** | With `CNAME` = `lp.betterengineer.com`, traffic is scoped to that hostname. The **`/aimanufacturing`** segment comes from the published folder name and **`SITE_BASE`**, not from the CNAME file. |

## 6. GitHub Pages limits (unchanged)

| Topic | Detail |
|--------|--------|
| **One CNAME per repo** | The **`CNAME`** file is only the hostname (`lp.betterengineer.com`). |
| **Jekyll** | **`.nojekyll`** at the **publish root** disables Jekyll. |
| **Rename path** | To use another slug (for example **`/ai-manufacturing`**), change **`OUTPUT_ROOT`**, **`--base`**, and the folder name in the workflow so they stay identical. |
